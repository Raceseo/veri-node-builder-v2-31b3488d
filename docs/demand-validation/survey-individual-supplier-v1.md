# 개인 공급자 수요 검증 설문 v1

이 문서를 기반으로 Google Form을 만들면 됩니다. 각 섹션 = Form의 한 페이지.

**예상 응답 시간**: 5~6분
**표본 목표**: 30명 (최소) / 50~100명 (목표)

---

## 페이지 1 — 시작 페이지 (설명)

**제목:**
```
내 데이터에 정당한 대가, 받으실 의향 있으신가요?
```

**설명 (Form 상단에 붙일 글):**
```
안녕하세요. verinode를 준비하고 있는 사람입니다.

기업은 매일 우리의 데이터로 돈을 법니다.
하지만 정작 데이터의 주인인 우리는 아무 것도 받지 못합니다.
verinode는 이것을 바꾸려고 합니다.

정부가 인증한 "진짜 나의 데이터"를 기업이 사 가고,
그 대가의 대부분을 데이터 주인인 당신에게 돌려드립니다.

이 설문은 5~6분이면 끝납니다.
응답해 주신 분께는 정식 출시 시 첫 설문 보너스 1,000원을 드립니다.
```

## 페이지 5 — verinode가 무엇인지

> **섹션 제목**: verinode는 이렇게 작동합니다

**설명 (페이지 상단에 Form 글로 넣기):**
```
1단계 (한 번만, 5분):
  정부24·은행 등에서 마이데이터 동의로 "진짜 당신의 데이터"를 인증합니다.
  verinode는 당신이 허락한 범위 안에서만 사용합니다.

2단계 (매번):
  기업이 "검증된 당신의 의견"을 원하면 설문이 도착합니다.
  응답 1건당 약 5,000원.
  한 달에 10건 정도 꾸준히 답하면 월 5만원 정도가 쌓입니다.

3단계:
  적립된 돈은 언제든 출금. 공짜로 가져가는 기업은 없습니다.
```

11. 지금 들으신 이 서비스에 **관심이 가시나요?** `[필수 · 객관식]`
    - 적극 참여하고 싶다
    - 조건이 맞으면 참여하겠다
    - 잘 모르겠다
    - 관심 없다

12. *(11번에서 "관심 없다"를 선택하셨다면)* 가장 큰 이유가 뭔가요? `[선택 · 주관식]`

## Google Form 만들 때 팁

1. **Form 설정**에서 "응답 1회 제한" 켜지 마세요 (로그인 요구하면 응답률 급락).
2. **페이지 이동** 기능 켜세요 (섹션마다 "다음" 버튼 필수).
3. **이메일 수집**은 Form 자체 기능이 아니라 **18번 질문**으로 수집 (자발성이 signal).
4. **진행률 표시**(Progress bar) 켜세요. 응답자 중도 포기 막는 효과.
5. 모바일 친화: 카카오 오픈채팅에서 링크 누르면 바로 열려야 함 → 짧은 URL(`bit.ly` 또는 Form 자체 단축 URL) 사용.
