# verinode 수요 검증 (Demand Validation)

verinode는 **수요 검증 우선** 원칙으로 움직입니다. 코드를 더 짓기 전에, 실제로 이 서비스에 돈을 낼 사람이 존재하는지부터 확인합니다.

## 현재 상태 (2026-04-23)

✅ MVP 온보딩 흐름 동작: 신규 회원 가입 → 서약 → 개인/기업 선택 → 마이데이터 연결 → `/dashboard` 진입
❌ Dashboard 안쪽 기능: 일부 테이블 미적용 상태 (수요 검증 후 복원 예정)

## 검증할 2개 세그먼트

| 세그먼트 | 질문 | 현재 진행 상태 |
|---|---|---|
| **개인 공급자** (Supplier) | 정부24 마이데이터 인증하고 설문 응답해서 건당 5,000원 받을 의향? | 📝 [설문 v1 초안 작성됨](./survey-individual-supplier-v1.md) |
| **기업 수요자** (Buyer) | 검증된 개인 데이터 1건에 7,000원 지불할 가치? | 🕐 개인 응답자 풀 확보 후 진행 예정 |

## 수요 검증 로드맵

```
[지금] 설문 초안 작성 (이 PR)
  ↓
사용자가 Google Form 제작 + 뿌리기
  ↓
[+1주] 30~100명 응답 수집
  ↓
[판정] 이메일 등록률 ≥40% → Go, 20~40% → 조정, <20% → Pivot
  ↓
(Go 시)
  ↓
Auth 페이지에 "사전 신청" CTA 추가 (PR 예정)
  ↓
[+2주] 기업 인터뷰 5곳 (개인 응답자 풀 실적으로 설득)
  ↓
(쌍방 수요 확인 시) Dashboard 기능 복원 + 실 런칭
```

## 설계 철학 (Mom Test)

> _The Mom Test_ (Rob Fitzpatrick) 원칙을 따릅니다.

1. **과거 행동을 묻는다**, 가상의 의향을 묻지 않는다.
   - ❌ "7,000원 받으면 참여하시겠어요?"
   - ✅ "지난 한 달 동안 몇 번이나 온라인 설문에 참여하셨나요?"
2. **추상 대신 구체**.
3. **실제 돈이 오갈 수 있는 action을 signal로 본다** (이메일 등록 = 가장 가벼운 commitment).

## 판정 기준

- **Go**: 이메일 등록률 **40% 이상**, 자유 답변에 "오 괜찮다" 류 피드백이 다수
- **조정**: 20~40% — 질문·브랜딩·가격 모델 재검토 후 v2
- **No-go**: <20% — 타겟이나 가치 제안 근본 재설계 (pivot)
