**왜 이 문구?**

## 응답 모이기 시작하면 (1주 단위로 반복)

1. 응답 수가 30개 넘어가면 **1차 중간 분석**
2. 이메일 등록률 계산 → Go/조정/No-go 신호
3. 가장 많이 선택된 "걱정" 항목 → 브랜딩·카피 조정
4. 가장 많이 선택된 "가격 하한" → 비즈니스 모델 조정 여지

자유 답변(주관식)에서 **반복적으로 나오는 표현**은 뽑아서 랜딩 페이지 카피로 재활용하세요.
이건 사용자가 직접 해주는 마케팅 문구입니다.
